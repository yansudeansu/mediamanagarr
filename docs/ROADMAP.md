MediaManagarr Roadmap

MediaManagarr is a browser extension for Jellyfin, Seerr, Sonarr, Radarr, and qBittorrent.

This roadmap tracks upcoming work, not completed features. Milestones are goals, not release dates.

Current priority

Milestone 1 — Up Next (Jellyfin)

Display recently added and unwatched media from Jellyfin.

- Display recently added movies and episodes.
- Use the Jellyfin user selected in Settings.
- Show media artwork, titles, release information, and dates.
- Add reusable filtering and pagination.
- Track new and unwatched items.
- Support notifications and marking items as seen.
- Handle missing artwork, empty results, and connection failures.
- Test API responses, background messaging, and user interactions.

Upcoming milestones

Milestone 2 — Calendar (Sonarr & Radarr)

Display upcoming television episodes and movie releases.

- Combine upcoming releases from Sonarr and Radarr.
- Add month navigation and date selection.
- Display release details and media artwork.
- Add filtering by service and media type.
- Handle missing information and service failures independently.
- Support keyboard navigation.
- Test calendar navigation, API responses, and date handling.

Milestone 3 — Downloads (qBittorrent)

Monitor and manage active downloads.

- Display torrents, progress, download speeds, upload speeds, and ETA.
- Show torrent states and download statistics.
- Support starting, stopping, and removing torrents.
- Require confirmation for destructive operations.
- Never delete downloaded files without explicit permission.
- Handle connection failures and authentication errors.
- Test download actions and error handling.

Milestone 4 — Service Health & Reliability

Improve the reliability of configured service integrations.

- Monitor configured services and connection health.
- Show clear connection and authentication errors.
- Add recovery indicators and useful troubleshooting messages.
- Improve request retries, timeouts, and error handling.
- Handle temporary service outages gracefully.
- Avoid unnecessary API requests.

Milestone 5 — Testing & Accessibility

Expand automated testing and verify accessibility across the extension.

- Add browser automation for critical workflows.
- Test extension permissions, storage, and background messaging.
- Expand cross-browser testing in Firefox, Zen Browser, and Chrome.
- Audit keyboard navigation and focus management.
- Review screen reader support and accessible status messages.
- Audit WCAG 2.2 AA accessibility.
- Fix issues identified during testing.

Testing and accessibility remain ongoing requirements throughout every milestone.

Milestone 6 — Feature Enhancements

Refine existing features based on real-world usage and feedback.

Potential improvements include:

- More advanced filtering and sorting.
- Expanded media details.
- More notification options.
- Improved download management.
- Cross-service activity and related media.
- Performance and usability improvements.

Enhancements will be prioritized based on user feedback rather than speculative requirements.

Milestone 7 — Branding & Documentation

Prepare MediaManagarr for a wider audience.

- Refine extension branding, icons, and artwork.
- Improve installation and configuration guides.
- Document supported services and required permissions.
- Add troubleshooting documentation.
- Improve contribution and development guides.
- Review screenshots and other release materials.

Milestone 8 — Release & Distribution

Prepare and publish MediaManagarr for supported browsers.

- Verify GitHub Release publishing with a real release.
- Test recovery after interrupted publishing.
- Validate release ZIPs and browser compatibility.
- Validate Firefox and Chromium extension packages.
- Test installation, updates, and upgrades.
- Prepare Firefox Add-ons and Chrome Web Store submissions.
- Document release and distribution procedures.

Future possibilities

Ideas that may be explored after the initial release:

- Standalone web application.
- Additional service integrations.
- Customizable dashboards.
- Richer cross-service features.

⸻

Milestones are complete when functionality is tested, documented, accessible, and verified in supported browsers.
