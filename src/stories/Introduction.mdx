Welcome to the **MediaManagarr component library**.

This Storybook documents the reusable interface components, visual foundations, and accessibility conventions used throughout MediaManagarr.

## Design principles

- **Consistency** — Shared components and tokens keep the interface predictable.
- **Accessibility** — Semantic HTML, keyboard interaction, and visible focus states.
- **Simplicity** — Build what the application needs without unnecessary abstractions.
- **Reusability** — Prefer composable components over duplicated implementations.

## Component organization

MediaManagarr follows a lightweight Atomic Design approach.

### Atoms

Small, reusable interface elements.

- **MmButton** — Button variants, sizes, and interaction states.
- **MmIcon** — Consistent icon rendering using Lucide.

### Molecules

Components composed from smaller interface elements.

- **MmHeader** — Application branding and navigation actions.
- **MmNavigation** — Main application navigation.
- **MmFooter** — Application branding and version information.

## Foundations

The design system uses shared CSS variables for colors, typography, borders, and motion.

Explore **Foundations → Design Tokens** for visual examples and token values.
