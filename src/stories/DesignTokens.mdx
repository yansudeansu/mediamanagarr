# Design Tokens

The visual foundation of **MediaManagarr**.

A shared design language for the browser popup, detached workspace, and future sidebar. All tokens are defined in `src/styles/tokens.css` and shared across application surfaces.

## Color Palette

The palette contains six color families with consistent shade naming.

Shades progress from **950 (darkest)** toward **100 or 300 (lightest)**. Neutral has additional light shades for text and supporting UI.

## Semantic Colors

Semantic tokens describe **what a color does**, not which shade it uses.

Components should prefer these tokens over palette values whenever possible.

This allows badges, alerts, and service indicators to communicate state without relying on color alone.

## Motion

Motion should feel responsive and unobtrusive.

The shared transition token is:

```css
--transition-fast: 150ms ease;
```
